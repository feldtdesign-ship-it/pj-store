# PJ O'Rourke II — shop preview

Static preview of the **Platform** Shopify theme (`../pj-theme`), rendered from the theme's own
Liquid files with PJ's live product data (256 products, 18 collections, pulled from pjorourkeii.com
on 2026-10-24). The bag works in the browser; checkout does not.

Live: https://feldtdesign-ship-it.github.io/pj-store/

Rebuild: `build/build.sh` (needs python-liquid). `build/build.sh --fresh` pulls new product data first.
Built by Feldt Design, October 2026.
